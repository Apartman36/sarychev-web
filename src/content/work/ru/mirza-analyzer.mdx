## Контекст

`mirza_analyzer` здесь описан как local analysis pipeline для exported chat data. Это secondary case, который показывает staged data handling и reporting.

## Проблема

Exported communication data сложно анализировать напрямую. Local pipeline помогает ingest, structure и report по этим данным.

## Подход

Проект использует staged flow: audit, ingest, SQLite storage, extraction и reports.
