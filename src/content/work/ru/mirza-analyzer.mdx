## Контекст

`mirza_analyzer` здесь описан как локальный analysis pipeline для exported chat data. Это дополнительный кейс, который показывает staged data handling и отчётность.

## Проблема

Exported communication data сложно анализировать напрямую. Локальный pipeline помогает принять, структурировать и описать эти данные в отчётах.

## Подход

Проект использует staged flow: audit, ingest, SQLite storage, extraction и отчёты.

## Результат

Кейс показывает мышление в формате local data pipeline и практическую отчётность по exported files.
