## Контекст

`browser_agent_mvp` - локальный browser agent, который управляет видимым Chromium через Playwright. Фокус проекта - практическая browser automation без заранее прописанных selectors для каждого действия.

## Проблема

Browser agents должны понимать меняющиеся страницы, выбирать действия, помнить недавние шаги и оставлять логи для ревью. Обычный selector script для этого слишком хрупкий.

## Ограничения

- Browser остаётся видимым для проверки.
- Действия описаны как structured tool calls.
- Agent loop требует памяти и логирования результатов.
- MCP server нужен для подключения внешних tools.

## Подход

Agent читает ARIA snapshot страницы, выбирает structured actions, выполняет их через Playwright, хранит память последних действий и пишет результаты в логи.

## Ключевые решения

- ARIA snapshots как слой представления страницы.
- Tool calls через schemas.
- Память последних действий против повторяющихся и противоречивых шагов.
- MCP server с browser tools для подключения внешнего agent.

## Результат

Проект показывает практическое проектирование agent loop для browser automation: явное состояние, видимое выполнение и проверяемые логи.

## Что это демонстрирует

Agent loop design, Playwright automation, MCP tools и browser workflows с ревью человеком.
